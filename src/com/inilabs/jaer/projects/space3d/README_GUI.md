# Space3D GUI

Adds a reusable Swing viewer for the Space3D XZ plane (North up).

- `Space3DPanel` — paintable panel with axes, grid, labels, mouse coord readout
- `Space3DGUI` — frame with sliders for scale and X/Z offsets, plus a status bar

**Usage**: Place these files under `com/inilabs/jaer/projects/space3d` alongside the core `Space3D` and agent classes. Run `Space3DGUI.main` for a demo.
